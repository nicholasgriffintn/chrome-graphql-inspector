# GraphQL Inspector

Inspect GraphQL requests and responses without leaving Chrome DevTools.

GraphQL Inspector helps developers understand and debug the GraphQL traffic generated by a website. It works with queries, mutations, subscriptions, batched requests and persisted queries.

![Screenshot](/screenshots/inspector.png)

Alongside the inspector, this extension also provides **GraphQLi**, a simple GraphQL client that can send GET and POST requests from the current page to the endpoint shown in DevTools.

![Screenshot](/screenshots/graphqli.png)

## Key features

- Find and filter GraphQL queries, mutations and subscriptions.
- Inspect formatted queries, variables, responses, headers and events.
- Split batched operations and show persisted-query details.
- Follow WebSocket and EventSource subscription messages.
- Search requests or show only responses with GraphQL errors.
- Copy requests as cURL, `fetch` or JSON.
- Send GET and POST operations from the current page with GraphQLi.

## Privacy

Your GraphQL traffic stays on your device. The extension has no analytics, telemetry, advertising, accounts, remote code or external services.

Captured traffic is kept temporarily in extension memory and is never written to extension storage. The only saved setting is **Preserve log**. GraphQLi sends a request only when you select **Send request**, directly from the inspected page to the endpoint shown.

## Why permissions are needed

- **Read data on all websites:** detect GraphQL traffic on any website you choose to inspect.
- **Read network requests:** match request bodies and headers with responses shown in DevTools.
- **Storage:** remember the Preserve log setting.

Captured traffic is grouped by tab and shown only in the matching DevTools panel.

## How to use it

1. Open the website you want to inspect.
2. Open Chrome DevTools.
3. Select the **GraphQL** tab.
4. Reload the page if no requests appear.

Select a request to view its query, variables, response, headers and timeline. Use **GraphQLi** to edit and resend a captured request or write one from scratch.

## Install from source

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this project folder.
5. Refresh any page that was already open.

## Development

No build step or runtime dependencies are required. Run the tests with Node.js 20 or later:

```bash
npm test
```

Package the extension with:

```bash
npm run package
```
